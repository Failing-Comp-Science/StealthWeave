You are a senior UI/UX designer and frontend engineer specializing in clean, modern, and user-friendly web interfaces for security and cryptography tools.

Build a beautiful, responsive, and intuitive UI/UX interface for an image steganography web application. The interface should support two primary modes:

1. **Encode Mode** — Embed a secret message/file into an image
2. **Decode Mode** — Extract a hidden message/file from an image

This is a UI/UX prototype only. No backend logic or actual steganography implementation is needed at this stage. Focus entirely on creating a polished, professional, and user-friendly interface that demonstrates the user flow and interaction design.

## Design Requirements

### Aesthetic & Style
- **Design Language:** Clean, minimalist, and modern with a security-focused aesthetic
- **Color Palette:**
  - Primary: Deep indigo or navy blue (#1E3A8A or #0F172A)
  - Secondary: Teal or emerald green (#14B8A6 or #10B981)
  - Accent: Purple or violet (#8B5CF6 or #7C3AED)
  - Background: Dark mode by default (slate or charcoal)
  - Text: White or off-white for contrast
- **Typography:**
  - Headings: Inter or Poppins (bold, modern)
  - Body: Inter or Roboto (clean, readable)
  - Monospace: JetBrains Mono or Fira Code (for code/message displays)
- **Visual Elements:**
  - Subtle gradients and glassmorphism effects
  - Smooth transitions and hover states
  - Icons from Lucide or Heroicons
  - Rounded corners (xl or 2xl)
  - Card-based layout with subtle shadows
- **Inspiration:** Linear, Vercel, Raycast, and modern crypto tools (e.g., 1Password, Bitwarden)

### User Flow

#### Landing Page / Home
- **Hero Section:**
  - Project name (e.g., "Harpocrates") with a tagline: "The Art of Concealed Communication"
  - Brief description: "Hide secret messages within images using advanced steganography techniques"
  - Two prominent call-to-action buttons: "Encode" and "Decode"
  - Optional: A subtle animated background or illustration showing hidden data in pixels

- **Features Section (Optional):**
  - 3-4 feature cards explaining:
    - "Secure Encryption" (AES-256)
    - "Lossless PNG Output"
    - "Drag & Drop Interface"
    - "Instant Extraction"

#### Encode Mode (Tab or Separate Page)
- **Header:**
  - Title: "Encode — Hide Your Message"
  - Subtitle: "Embed a secret message or file into an image"
  - Back button to return to home

- **Step 1: Upload Cover Image**
  - Large drag-and-drop zone with a dashed border
  - Icon: Upload or Image icon
  - Text: "Drag and drop your image here, or click to browse"
  - Supported formats: PNG, JPG, BMP, WebP (display as badges)
  - After upload:
    - Show a thumbnail preview of the uploaded image
    - Display file name, size, and dimensions
    - Option to remove/replace the image

- **Step 2: Enter Secret Message**
  - Textarea for entering the secret message
  - Placeholder: "Enter your secret message here..."
  - Character counter (e.g., "0 / 1000 characters")
  - Optional: File upload button to attach a file instead of text
    - Shows selected file name and size
    - Option to remove the file
  - Optional: Password field for encryption
    - Label: "Encryption Password (optional)"
    - Placeholder: "Enter a password to encrypt your message"
    - Eye icon to toggle password visibility

- **Step 3: Encode Button**
  - Primary action button: "Encode Image"
  - Loading state: Show a spinner or progress bar when clicked
  - Tooltip: "This will embed your message into the image"

- **Step 4: Download Stego Image**
  - After encoding (simulated):
    - Show a success message: "Your message has been hidden!"
    - Display the stego image (same as cover image visually)
    - Show stats: "Image size: 2.4 MB | Capacity used: 12%"
    - Download button: "Download Stego Image"
    - Option to encode another image

#### Decode Mode (Tab or Separate Page)
- **Header:**
  - Title: "Decode — Reveal Hidden Message"
  - Subtitle: "Extract a hidden message from an image"
  - Back button to return to home

- **Step 1: Upload Stego Image**
  - Large drag-and-drop zone (same design as encode mode)
  - Icon: Upload or Lock icon
  - Text: "Drag and drop the image with hidden data, or click to browse"
  - After upload:
    - Show thumbnail preview
    - Display file name, size, and dimensions
    - Option to remove/replace the image

- **Step 2: Password Field (Optional)**
  - Label: "Encryption Password (if encrypted)"
  - Placeholder: "Enter the password used during encoding"
  - Eye icon to toggle visibility

- **Step 3: Decode Button**
  - Primary action button: "Decode Image"
  - Loading state: Show a spinner or progress bar
  - Tooltip: "This will extract the hidden message from the image"

- **Step 4: Display Extracted Message**
  - After decoding (simulated):
    - Show a success message: "Message extracted successfully!"
    - Display the extracted message in a monospace font within a styled card
    - If the message is long, show it in a scrollable textare...
